Makes up names in a fantasy style, each with a button that adds it to the encyclopedia as a person. Run it from Project Home or from an encyclopedia entry.

There are nine styles: elvish (Welsh), high elvish (Finnish), dwarvish (Old Norse), old kingdom (Old English), imperial (Latin), mythic (Ancient Greek), highland (Gaelic), forest (Slavic), and orcish. Most are built to sound like the real names of the language in brackets, which ship with the plugin. You choose feminine, masculine, or any given names, how many to make (up to 20), and whether they come with second names.

The real names are from Wiktionary, shared under CC BY-SA 4.0, and Wikidata. The package's `resources/styles/NOTICE.txt` lists each source.
