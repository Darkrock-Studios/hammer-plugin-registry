Exports the story as one Markdown document, for blogs, static sites, and anywhere else that takes Markdown. The project's name is the title and each chapter a heading, and each scene is written as Hammer stores it, so the Markdown is your own, untouched.

Hammer's images are left out, since nothing outside Hammer can show them. For the story with its images, use Hammer's own Markdown export, which writes a ZIP of the story with its images.

Its setting numbers the chapter headings, as in `## 2. The Pool of Tears`.
