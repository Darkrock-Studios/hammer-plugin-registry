An MCP server for AI agents, run as the `hammer mcp` command on desktop. An agent that speaks the [Model Context Protocol](https://modelcontextprotocol.io) starts it and gets Hammer's operations as tools. It can always read your projects: scenes and drafts, notes, encyclopedia entries and their images, ideas, timelines, tags, and writing stats, and it can search and export them. It never writes your prose: no tool changes a scene's text.

Two settings, both off by default, let an agent do more. One lets it make changes: organize scenes, and edit outlines, tags, references, notes, encyclopedia entries, images, timelines, and ideas, and make backups. The other lets it delete scenes, drafts, notes, entries, images, timeline events, and ideas, but never a whole project. No setting lets it install or remove plugins.

It works whether Hammer is open or not. With the app running, an agent's changes show up in the open project.
