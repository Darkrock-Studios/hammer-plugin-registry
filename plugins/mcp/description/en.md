An MCP server for AI agents, run as the `hammer mcp` command on desktop. An agent that speaks the [Model Context Protocol](https://modelcontextprotocol.io) starts it and gets Hammer's operations as tools. It can always read your projects: scenes and drafts, notes, encyclopedia entries, ideas, the timeline, tags, and writing stats, and it can search and export them. It never writes your prose: no tool changes a scene's text.

Three settings, all off by default, let an agent do more. One lets it make changes: organize scenes, and edit outlines, notes, references, encyclopedia entries, the timeline, and ideas. One lets it delete scenes, drafts, notes, entries, timeline events, and ideas, but never a whole project. The last lets it install and remove plugins; a plugin an agent installs gets every permission it asks for without Hammer asking you.

It works whether Hammer is open or not. With the app running, an agent's changes show up in the open project.
